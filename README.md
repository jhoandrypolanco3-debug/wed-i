# LaunchPilot AI — MVP (base para ejecutar localmente)

Este branch contiene la base mínima del proyecto LaunchPilot AI para que puedas abrirlo y ejecutarlo localmente en tu equipo. Está pensado para un estudiante principiante (español), sin costes externos.

Contenido en este branch:
- Frontend (React + Vite, TypeScript mínimo): interfaz con un asistente AI local (plantillas) y editor simple.
- Backend (Node + Express): endpoint mínimo y servicio de compilación simulado.
- Analizadores (regla de ejemplo FTC): heurística para detectar hardwareMap.get.
- Tests básicos (Jest) para la regla FTC.

Instrucciones rápidas para ejecutar (ver más abajo para detalles):
1. git clone https://github.com/jhoandrypolanco3-debug/wed-i.git
2. cd wed-i
3. git checkout mvp/initial-app
4. npm install
5. npm run start:frontend
6. npm run start:backend

Lee README.md para más detalles.
